## Lexiloom UI 设计方案：丝滑的纸质感工坊
### 1. 设计参考对标
*   **暖色调与氛围**：参考 **Claude.ai**。学习它如何用“米白+深棕”营造温暖的阅读氛围，放弃冷冰冰的科技蓝。
*   **交互与流畅度**：参考 **Linear.com**。Linear 是业内公认的“丝滑”标杆，它的特点是：**微妙的悬停反馈、无阴影的扁平设计、GPU 加速的过渡动画**。我们将借鉴这种“轻量级高级感”。
*   **卡片与排版**：参考 **Craft.do**。学习它的“块级文档”设计，干净、有呼吸感，不依赖厚重阴影。
### 2. Design Tokens（设计变量）
请 Agent 在 `tailwind.config.js` 或全局 CSS 中维护这些变量，确保风格统一且易维护。
```css
:root {
  /* 01. 色彩系统 - 温暖的中性色 */
  --color-canvas: #F6F4EF;       /* 亚麻画布：主背景，不刺眼 */
  --color-surface: #FFFFFF;      /* 纸张白：卡片/工作台背景 */
  --color-surface-hover: #FAF9F6;/* 微交互：悬停时的微微泛黄 */
  
  --color-text-primary: #1C1814; /* 墨棕：主文字，比纯黑柔和 */
  --color-text-secondary: #7A7368;/* 羊毛灰：辅助信息，降低对比度 */
  
  --color-brand: #4A6FA5;        /* 靛蓝：品牌色，用于强调和编织线 */
  --color-accent: #C17A4E;       /* 陶土橙：极少量点缀，如搜索高亮 */
  
  --color-border: #E8E4DE;       /* 织纹灰：边框线，若有若无 */
  
  /* 02. 交互变量 - 保证丝滑的关键 */
  --ease-out-smooth: cubic-bezier(0.4, 0, 0.2, 1); /* 标准缓动曲线 */
  --duration-fast: 150ms;        /* 快速反馈 */
  --duration-normal: 250ms;      /* 标准过渡 */
}
```
### 3. 排版美学（零成本提升优美感）
字体是性价比最高的“特效”。
*   **单词本体**：
    *   **风格**：衬线体，具有书卷气和权威感。
    *   **实现**：`font-family: 'Georgia', 'Times New Roman', serif;`（系统自带，加载速度为 0ms）。
    *   **字号**：大号（20px+），营造视觉焦点。
*   **UI 界面**：
    *   **风格**：无衬线体，干净利落。
    *   **实现**：系统默认栈 `-apple-system, BlinkMacSystemFont...`。
    *   **行高**：`1.6`。增加行间距是提升“呼吸感”的关键，这也是一种“轻量化”设计，减少了视觉噪音。
### 4. 组件设计方案
#### A. 左栏：词库列表
**设计理念**：像一排整齐挂在墙上的工具。
*   **列表项**：
    *   **默认态**：背景透明。左侧有一条 3px 的竖线（`var(--color-border)`），代表“未激活的线”。
    *   **悬停态**：背景填充 `var(--color-surface-hover)`。**性能提示**：仅改变 `background-color` 和 `border-color`，无阴影，无位移，渲染成本极低。
    *   **选中态**：背景填充 `var(--color-surface)`（纯白）。左侧竖线瞬间变为 `var(--color-brand)`（靛蓝），并加粗至 4px。
    *   **交互细节**：选中时，卡片右侧会有一个微弱的向右箭头提示（`→`），通过 `opacity` 控制显隐。
#### B. 右栏：单词工作台
**设计理念**：一张平铺的白纸，静待书写。
*   **容器**：
    *   纯白背景 `var(--color-surface)`。
    *   **无阴影设计**：为了轻量化，我们取消阴影，改用**极细边框** `1px solid var(--color-border)`。这既界定了工作区，又消除了阴影带来的渲染负担。
*   **字段区分**：
    *   **词典数据（只读）**：背景色为 `var(--color-canvas)`（比工作台略深一点），文字为 `var(--color-text-secondary)`。视觉上“退后”，作为背景参考。
    *   **用户数据（可编辑）**：背景色为 `var(--color-surface)`（纯白），文字为 `var(--color-text-primary)`。视觉上“突出”，吸引用户聚焦。
    *   **输入交互**：
        *   空字段：虚线边框 `border: 1px dashed var(--color-border)`。
        *   聚焦输入：边框变为实线，颜色变为品牌蓝。这里可以加一个极其微妙的缩放效果 `transform: scale(1.005)`，让输入框仿佛“浮起来”一点，吸引用户注意。**性能提示**：`transform` 是 GPU 加速的，不触发重排，非常丝滑。
#### C. 编织线的视觉隐喻
*   **位置**：单词卡片左侧。
*   **动态**：当用户添加了一条个人笔记，左侧线从灰变蓝。
*   **实现**：CSS Transition (`transition: all 0.2s ease`)。
*   **意义**：隐喻“知识已被编织入网”。
### 5. 高级轻量化动效
以下是允许使用的“高级效果”，均在 GPU 层运行，不会导致卡顿：
1.  **卡片反馈**：
    *   鼠标悬停时，卡片不要用复杂的阴影浮现。
    *   **方案**：使用 `transform: translateX(2px)`。卡片微微向右移动 2 像素。这模拟了“从架上取出”的物理感，且极其流畅。
2.  **页面转场**：
    *   切换单词时，右侧工作台不要硬刷新。
    *   **方案**：使用淡入淡出 `opacity: 0 -> 1`。配合 100ms 的短促动画，让大脑感觉不到加载延迟。
3.  **编织完成微动画**：
    *   当用户保存笔记时，左侧竖线变蓝。
    *   **方案**：不仅变色，可以加一个极短的 `animation: pulse 0.5s`。线条瞬间变粗一点再回弹。这是一种“确认感”，令人愉悦且不消耗资源。
### 6. 性能与维护红线
为了保证长期使用的流畅性，请在 Prompt 中明确告知 Agent 以下禁忌：
1.  **严禁使用 `box-shadow` 做大面积交互**：阴影渲染昂贵，尤其是在滚动列表时。
2.  **严禁使用 `filter: blur()`**：模糊滤镜是性能杀手。
3.  **严禁在动画中使用 `width/height/margin/padding`**：这会导致页面“重排”，引起卡顿。
4.  **长列表优化**：如果词库超过 100 条，请 Agent 在列表组件中使用虚拟滚动技术（如 `react-window`），确保只渲染可视区域内的 DOM 节点。

### 最终指令
> 请根据以下《Lexiloom UI 设计规范》重构界面。重点在于实现“丝滑、轻量、有温度”的视觉体验。
>
> **1. 样式基础：**
> *   提取所有硬编码颜色到 `:root` CSS 变量。
> *   背景：亚麻白 `#F6F4EF`；卡片：纯白 `#FFFFFF`；文字：深墨棕 `#1C1814`。
> *   移除所有组件的硬编码阴影，改用细边框 `#E8E4DE` 或背景色变化来区分层级。
>
> **2. 排版策略：**
> *   单词名称改用衬线体（如 `font-serif`），字号 20px+。
> *   UI 文字使用无衬线体，行高 1.6，营造呼吸感。
>
> **3. 交互与动效（轻量化）：**
> *   左侧“编织线”：默认灰色 `#D9D4CE`，有内容时变为靛蓝 `#4A6FA5`，使用 `transition: all 150ms ease`。
> *   列表悬停：背景变色（不加重绘），并使用 `transform: translateX(2px)` 提供微交互反馈。
> *   输入框聚焦：边框由虚线变实线，严禁使用阴影浮现。
>
> **4. 性能保障：**
> *   确保所有动画仅涉及 `transform` 和 `opacity`。
> *   检查列表渲染逻辑，确保大数据量下不会因 DOM 节点过多而卡顿。
> 这套方案既满足了你对“Claude 式”温暖色调的喜爱，又通过去掉阴影、纹理和复杂动画，确保了软件在未来几十年的长期使用中，依然能保持启动秒开、滚动如丝般顺滑。
